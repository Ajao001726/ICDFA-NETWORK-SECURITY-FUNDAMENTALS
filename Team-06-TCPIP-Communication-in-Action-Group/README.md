#Tracing an HTTPS Request Across the TCP/IP Model
A group project by junior network analysts. This Network Communication Project contains a presentation on how information travels across a network when a user opens a secure website (HTTPS), from the sending device to the destination and back.

##Scenario
Opening a secure website using HTTPS.

##The Presentation Covers
Scenario: Opening a secure website and how communication begins.
Application Layer: Role of the web browser, DNS, HTTP, and HTTPS.
Transport Layer: How TCP establishes a reliable connection and how UDP differs from TCP.
Internet Layer: IP addressing, routing, and how data travels between networks.
Network Devices: Roles of routers, switches, and other devices in communication.
OSI Model: Mapping TCP/IP layers to the OSI model.
Encapsulation & Decapsulation: How data is packaged and unpackaged as it moves through the network.
Troubleshooting: Common network problems, such as DNS errors, and basic ways to identify them.
Secure Communication: How HTTPS and other network processes help protect information during transmission.
Practical Example: The complete journey from entering a website address to receiving the webpage.
